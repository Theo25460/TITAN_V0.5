# TITAN Android (native) — notes for contributors and agents

Native Android client of TITAN (`fr.titanapp.app`), React Native + TypeScript on Expo SDK 57 with Continuous Native
Generation: `android/` is generated by `npx expo prebuild` and is not committed. No WebView, TWA or Custom Tab renders
TITAN screens; external links (legal texts, help centre) open in the browser on purpose.

- Navigation: React Navigation (native stack + bottom tabs), not Expo Router (it pulled incompatible peer versions).
- Backend: the production Supabase project shared with titan-app.fr. Same tables and RPCs as the website; XP,
  credits, possession and progression are only written by server functions. Never ship a server secret.
- Business rules: `src/core/web/*.js` are unchanged copies of the website modules (effort/XP, sports, progression,
  records, campaign). Re-sync with `node scripts/sync-web-core.mjs <web checkout> <sha>`; a test checks the hashes.
- Offline: sessions go through `src/data/queue.ts` (durable per-account queue, idempotent `client_event_id`).
- Install packages with `EXPO_OFFLINE=1 npx expo install <pkg>` (the Expo API is not reachable from the cloud sandbox).
- Checks: `npm run typecheck`, `npm test`, `npx expo export:embed --platform android --dev false --entry-file index.ts
  --bundle-output /tmp/b.js --assets-dest /tmp/a`. The Gradle build runs in `.github/workflows/android-native.yml`.
