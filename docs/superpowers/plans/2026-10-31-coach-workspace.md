Goal: continue the existing V1.1 cahier COACH-03/04/06 with three independently testable increments. Base PR #123, remote 8e6cad0. No Netlify or other production deployment.

1. COACH-03 roster overview. Use only the existing snapshot's active coach-owned relationships. Search names (case/diacritic insensitive) and filter the shared sport; a relation covering all sports matches every sport filter. Show selected athlete and consent start. No invented workload/status/health metric and no automatic per-athlete reads. Behind screens.coachworkspace false. Preserve filter/focus during updates, erase on account/mode change. Clicking an athlete reuses existing detail loading and context validation.
2. COACH-04 proposal calendar. A month list with previous/next month and today buttons, UTC dates, status filter and per-day grouping. Uses only selected relationship's loaded assignments, with explicit loaded/total coverage and no assertion that an empty partial page means no programme. Status labels distinguish proposed/accepted/completed/declined/cancelled. No calendar edit, forced acceptance or extra API reads. Behind screens.coachcalendar false. Preserve focus after navigation and reset when account/athlete changes.
3. COACH-06 CSV. Explicit Coach-only download behind screens.coachexport false. On click, get fresh snapshot, verify same active owner/athlete/link/revision, refetch every session page for the selected dates (100/page, max 100 pages), validate envelope owner/link/revision/bounds/total consistency, then get a final snapshot with unchanged scope. Abort on context, athlete, date, mode or flag change, revoked scope, network failure, malformed/partial pages or duplicates. Only export UTC date, sport identifier, numeric value, unit and directly provided duration; never notes, GPS, health, personal names or raw arbitrary details. Include effective dates and source in CSV; sanitize text cells against spreadsheet formulas. Explicit missing duration is blank, known zero is zero. Use UTF-8 BOM/semicolon/CRLF. No cached download URL, revoke object URL immediately; explain downloaded copies cannot be recalled. Show progress/error without losing forms. Prevent double click/concurrent export.
