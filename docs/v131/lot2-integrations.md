# Lot 2 · Intégrations (Garmin, GPX, Santé Connect, pas, GPS natif, Google, e-mail, exports)

Périmètre : chemins réels du code, pas les documents. Google Play Billing est hors lot.
Rien n'a été publié ni écrit en production. Une migration a été ajoutée au dépôt (`20261114180000_v131_import_dedupe.sql`), non appliquée en production.

## Niveaux de preuve utilisés

- **simulé** : test unitaire, fournisseur et base remplacés par des doublures. Ne prouve jamais une connexion réelle.
- **rejoué localement** : exécuté sur une base PostgreSQL 16 jetable portant toutes les migrations du dépôt, comptes synthétiques, tout annulé en fin de script. La production utilise PostgreSQL 17.6.
- **calculé** : mesure rejouée localement sur les vraies fonctions (taille d'un enregistrement, temps d'analyse).
- **relu** : lecture du chemin de code, avec fichier:ligne.
- **non vérifiable ici** : demande un compte Garmin réel, un téléphone avec Santé Connect, un GPS physique ou un retour Google réel.

Aucune ligne de ce document ne décrit une connexion réelle à Garmin, Santé Connect, Google ou à un GPS physique.

## SQL

### Ligne à ajouter à `tools/db/postflight-v131.sql` (lecture seule)

Ajouter `('20261114180000')` à la liste `versions`, puis :

```sql
union all
select 'import dedupe:a session saved now is matched by its end, empty search_path, closed to API roles', coalesce((
  select position('l.created_at - l.date between' in f.prosrc) > 0 and position($m$'hasGpx'$m$ in f.prosrc) > 0
     and f.prosecdef and exists (select 1 from unnest(f.proconfig) c where c = 'search_path=""')
     and not has_function_privilege('anon', f.oid, 'EXECUTE') and not has_function_privilege('authenticated', f.oid, 'EXECUTE')
    from pg_proc f where f.oid = to_regprocedure('private.titan_import_core(uuid,text,text,text,timestamptz,numeric,numeric)')), false)
```

Vérifié sur la base locale : `f` avant la migration, `t` après.

select reference, category, created_at, notification_state, notification_first_attempt_at
