# Sélection provisoire

Exports WebP en 96 et 256 pixels, classés par identifiant du catalogue. La sélection est partielle et reste à contrôler, notamment le détourage, la lisibilité en petit et les différences entre disciplines voisines. Les nouveaux visuels ne sont pas approuvés. Rien n’est intégré à l’application.

Les images originales sont conservées séparément ; ces WebP sont des dérivés, pas des masters. Pour une intégration future, choisir la taille adaptée, charger seulement les images nécessaires et prévoir une image de repli pour les identifiants absents.
